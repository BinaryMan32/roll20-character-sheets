# Greenland Character Sheet for Roll20

A comprehensive character sheet for the **Greenland** RPG system designed by Eric Green, optimized for use on Roll20.

## Overview

Greenland is a role-playing system that combines narrative storytelling with tactical gameplay decisions using six-sided dice as the primary resolution mechanic.

## Features

- **Complete Character Creation Support**: Full support for creating characters including traits, attributes, skills, and jobs
- **Attributes System**: Manages four core attributes (Strength, Agility, Endurance, Awareness) with automatic level tracking
- **Skills Management**: Includes general skills, defensive skills, and fighting styles with five proficiency levels each
- **Combat Tracking**: Stamina management, wound tracking, and health status monitoring
- **Equipment Inventory**: Track armor, weapons, and items with weight calculations
- **Character Values**: Define character personality and motivations through value extremes
- **Responsive Design**: Works on desktop, tablet, and print-friendly format

## Character Creation Steps

1. **Basic Information**
   - Character name, player name
   - Age (affects attribute/skill caps)
   - Height and weight (determines carrying capacity)

2. **Traits** (assign 3, 2, 1 to)
   - Memory
   - Toxin Resistance
   - Disease Resistance

3. **Attributes**
   - Strength (carrying, lifting, pushing/pulling)
   - Agility (movement, balance, coordination)
   - Endurance (stamina, pain tolerance)
   - Awareness (observation, intuition, reactions)

4. **Skills**
   - General Skills (Legerdemain, Linguistics, Logic, Mechanics, Survival)
   - Defensive Skills (Parry, Deflect, Dodge)
   - Fighting Styles (Unarmed Melee, Armed Melee, Ranged-Shot, Ranged-Thrown)

5. **Jobs & Occupations**
   - Select primary job with expertise depth
   - Jobs provide knowledge, skills, and social connections

6. **Character Values**
   - Select 2 extremes from the values spectrum
   - Defines personality and motivation

7. **Equipment**
   - Armor selection
   - Weapon inventory
   - Other carried items
   - Weight tracking

## Key Mechanics

### Attributes & Skills Levels

**Attributes**: Frail (-2d6), Weak (-1d6), Normal (1d6), Exceptional (+1d6), Legendary (+2d6)

**Skills**: Inexperienced (-2d6), Novice (-1d6), Journeyman (1d6), Expert (+1d6), Master (+2d6)

### Stamina System

- Replenishes at the start of each round
- Used to perform actions and reactions
- Affects movement and combat capabilities

### Wound Tracking

- **Minor Wounds**: Superficial injuries
- **Major Wounds**: Serious injuries (2 minor = 1 major)
- **Imminent Death**: Critical condition (2 major = imminent death)

### Size & Carrying Capacity

- Character height and weight determine physical capabilities
- Strength attribute affects carrying capacity
- Weight affects movement speed and combat abilities

## Combat System

The sheet supports Greenland's combat mechanics including:

- Action and reaction tracking per round
- Defensive skill options
- Weapon and armor management
- Stamina expenditure tracking
- Condition management (disoriented, fearful, bodily discomfort, etc.)

## Tabs Included

1. **Basic Information** - Character details and traits
2. **Attributes** - Core physical and mental attributes with derived stats
3. **Skills** - Combat and non-combat skills
4. **Jobs & Values** - Occupations and personality values
5. **Combat & Health** - Wounds, conditions, equipment, and inventory
6. **Notes** - Character background, personality, and notes

## System Requirements

- Roll20 account
- Any modern web browser
- No API scripts required (sheet is standalone)

## Tips for Play

1. **Stamina Management**: Keep track of stamina expenditure carefully during combat
2. **Attribute Balance**: Remember that improving one attribute may require decreasing others
3. **Skill Focus**: Specialize in 2 Legendary/Master skills maximum (for realism)
4. **Weight Limits**: Monitor carrying capacity, especially during adventures
5. **Narrative First**: Use conditions and descriptions to enhance roleplay
